JA SHA512 HASH

Program realizowany w technologii WPF, służy on do haszowania łańcuchów znaków za pomocą użycia algorytmu SHA-512, część algorytmu haszowania realizowa w asemblerze lub c#, zależnie od wyboru użytkownika w checkboxie, możliwość korzystania z wielu wątków za pomocą slidera w graficznym interfejsie użytkownika.
